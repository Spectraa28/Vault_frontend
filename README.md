# The Vault · browser game

A standalone Vite / React / TypeScript frontend. All application, test, asset and build files live in this folder. Backend files are unchanged by this frontend.

```sh
cd frontend
npm install
npm run dev
```

Open [the live game](http://127.0.0.1:5173/) or [the recorded tour](http://127.0.0.1:5173/?replay=1).

The only environment setting is `VITE_API_URL`, defaulting to `http://localhost:8787`. Run against the backend described in [API.md](../API.md). The frontend reads `/api/health` before starting a live session. If `needsCode` is true, it asks the player for a code and sends it in the `x-access-code` header. The code is held only in component memory; it is not saved to storage. No backend credentials are needed by this frontend. This is a Vite public setting, not a secret.

## Recorded tour

`?replay=1` selects replay explicitly and labels every screen. `public/recordings/mock-run.json` is an unchanged copy of `../web/mock-run.json`. Run `npm run recording` after that upstream recording changes. Replay shows the original line before playing it; arbitrary text is available only in live mode. Outcomes are never selected from what a player types. Choose **Customer** to begin the saved Gus conversation. The manager badge has separate recorded Wren lines. The recording demonstrates levels 2, 3 and 5; the UI does not manufacture levels 1 or 4.

Banter takes 2 seconds; multi-event turns take roughly 5–15 seconds. The saved long hold is compressed to 12 seconds, visibly labelled as shortened replay. Live holds have no frontend timeout and show elapsed time, since the API does not provide a deadline. Only server decisions stamp a receipt. Reply `attempts` reconcile the receipts with the bank mutation record. `enforcementHeld: false` is a visible error and suppresses the normal ending claim.

## Controls

- WASD / arrow keys walk; Shift jogs. Jump is disabled.
- Drag the scene to orbit; Q / R rotate from the keyboard. ecctrl also supports gamepad movement and camera sticks.
- Enter a character’s ring and press E, or click the talk prompt.
- Enter sends; Shift + Enter inserts a newline. Hold the microphone to dictate; release, review, then send. Browser speech recognition is optional; typing always works. Browser-provided speech recognition may use the browser vendor’s service.
- Escape leaves a conversation without cancelling the server turn. Its events continue to be collected. Starting another conversation, switching identity and leaving the bank are disabled while that request is in flight.
- A touch joystick and a talk button appear on coarse-pointer devices. Drag the scene to orbit.
- Graphics High / Medium / Low, mute, and keyboard help are at the lower right.

## Verification

```sh
npm test
npm run build
```

The unit tests cover fragmented POST/SSE parsing, UTF-8/CRLF/keep-alives, terminal errors, interrupted streams, runtime validation, repeated/delegated tool matching, reply reconciliation, server-only unlocks, enforcement failures and the unchanged recording. They use no real model or ArmorIQ requests.

## Assets and honest limits

The world is deliberately built from procedural boxes/capsules and original low-poly figures. The bank geometry, marble texture, reflection environment and WAV sound effects are local, so it boots without external assets. The HDR environment is a small authored night-light approximation, not a photographed location. Audio sources are original procedural placeholders, generated by `scripts/make-audio.py`; no third-party samples. Liberation Serif is bundled with its OFL license in `public/fonts`.

`src/scene/Actor.tsx` exposes `characterModels` for later compressed, licensed GLB replacements. Name animation clips `Idle`, `Walk`, `Jog`, `Working` and the API mood names. No Mixamo assets or character voice files have been supplied. `voice(url)` is the reply-audio hook for a future server `audioUrl`. Current characters use procedural idle, gait, work and mood poses. The vault door always remains physically closed; that visual is not evidence of backend enforcement. Read the receipt’s bank record and enforcement status.

The three area modules lazy-load. Rain is one point cloud, dust uses instancing, reflection uses a static HDR, and only one active-area light casts shadows. Low disables shadows and post-processing. The 60 fps target requires measurement on actual mid-range hardware; it is not guaranteed by a successful build. High-only depth of field, local graphics controls and reduced-motion cuts are provided. Camera collision comes from ecctrl; furniture and doors use Rapier colliders.
